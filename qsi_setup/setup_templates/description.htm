Welcome to TDEClamUI Setup

TDEClamUI is a fast, lightweight, native ClamAV antivirus frontend crafted specifically for the Trinity Desktop Environment (TDE) and Q4OS.

Key Features:

  • High Performance: Native C++/TQt3 codebase with near-instant startup.
  • On-Demand Scanning: Flexible scan targets with customizable profiles.
  • Unofficial Databases: SaneSecurity and URLhaus malware feeds with automated live updates.
  • Security Audit: System security auditing tailored for Trinity desktop.
  • Quarantine Management: Secure isolation and file inspection.
